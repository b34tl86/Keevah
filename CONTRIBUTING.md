# Contributing

Thanks for wanting to make Keevah better. Its source code is private, so this repository doesn't take pull requests. Here's how you can help instead.

## Report a bug

1. Check that it still happens on the [latest release](https://github.com/b34tl86/Keevah/releases/latest).
2. Search the [existing issues](https://github.com/b34tl86/Keevah/issues?q=is%3Aissue) in case someone has already reported it. If they have, add what you know there.
3. Otherwise, open a [bug report](https://github.com/b34tl86/Keevah/issues/new/choose) and fill in the form: your version and system, the steps, what you expected and what happened instead.

Keep customer data out of it: no callers' names or numbers, transcripts, call recordings, passwords or keys.

## Suggest an idea

Start a discussion in [Ideas](https://github.com/b34tl86/Keevah/discussions/categories/ideas). Say what you're trying to do and why it matters to you; a real example, with the names changed, helps most. A 👍 on an idea that's already there counts too. Ideas help shape the [roadmap](ROADMAP.md).

## Ask a question

Ask in [Discussions → Q&A](https://github.com/b34tl86/Keevah/discussions/categories/q-a).

## Report a security problem

Privately, never in public. [SECURITY.md](SECURITY.md) explains how.

## Be kind

Everyone here follows the [code of conduct](CODE_OF_CONDUCT.md).
